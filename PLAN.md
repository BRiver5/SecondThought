# Second Thought — План реализации

> «Hold the urge, buy what lasts.»
> Трекер «без спонтанных покупок»: каждая хотелка ставится на паузу, срок паузы
> подбирает модель угасания желания, которая учится на твоих же решениях.

## 0. Архитектура

Полностью локально: `expo-sqlite`, без сети (INTERNET заблокирован), без аккаунта.

| Разрешение | Зачем |
|---|---|
| `POST_NOTIFICATIONS` | необязательное напоминание «пауза закончилась» (выключено по умолчанию, только в установленной сборке) |
| `VIBRATE` | haptics на тапах/свайпах, выключается в Settings |

## 1. Движок (`src/lib`, связка модулей)

1. `desire.ts` — **накапливаемая** модель: скорость угасания желания λ ~ Gamma,
   отдельно общий уровень, категории (частичное объединение, POOL=3) и триггеры
   (множитель скорости, стянутый к 1), забывание 0.97 на наблюдение.
   Предсказательная выживаемость — Ломакс `S(t) = (b/(b+t))^a`. Отпустил —
   интервально-цензурированное угасание (между последним «ещё хочу» и решением),
   купил после паузы — правое цензурирование. `MODEL_VERSION` + пересборка из журнала.
2. `cooling.ts` — срок паузы как оптимум `цена·(1−S(t)) − зуд·∫S`; в закрытой
   форме `t* = a·цена/зуд − b` (риск угасания завтра = зуд/цена), ограничения min/max.
3. `budget.ts` — фонд «на хотелки» с переносом и потолком; созревшие хотелки —
   точный 0/1-рюкзак; конфликты с альтернативами, каждая проверена пересчётом
   (купить вместо X+Y, следующий месяц / накопить N месяцев, подержать 14 дней
   с условной вероятностью угасания, отпустить), ранжирование по цене в «очках желания».
4. `forecast.ts` — Монте-Карло на 12 недель: Гамма-Пуассон частоты хотелок,
   бутстрэп цен/категорий, время угасания из апостериора; общий seed для what-if.
5. `track.ts` — стрик (покупка после паузы стрик не рвёт), Брайер-калибровка.

## 2. Экраны (6)

1. Home — **Rail + Sections**: hero (накрутка «сохранено», стрик, полоса фонда) →
   лента билетов-пауз → липкие секции «Ready to decide» (свайпы Let go / Buy,
   long-press меню) и «Still cooling» (инлайн чек-ин).
2. `want/[id]` — деталь: интерактивная кривая S(t), «Why N days» с разложением,
   what-if (цена/зуд, до/после с дельтой), журнал чек-инов, инлайн-правка цены.
3. Plan — фонд, лучший набор, конфликты с ранжированными вариантами, what-if
   лимита (переигрывание всей истории фонда), прогноз Монте-Карло с what-if.
4. History — живой поиск, фильтры, липкие месяцы, long-press (undo/delete).
5. Stats — 7 секций, донат по категориям перестраивает все остальные.
6. Settings — фонд, потолок переноса, валюта, зуд/день, максимальная пауза, напоминания, вибрация.

## 3. Дизайн

Акцент оливковый мох `#505D28`, «хочу» — абрикос `#D9774B`, честная покупка —
сланцевый `#4D6A8A`, фон шалфейная бумага `#EDEFE8`. Анимации на timing
(motion.ts), press — spring PressableScale.
